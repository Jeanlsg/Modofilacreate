⏳ Status do Banco de Dados

Gere o JSON primeiro para ver as instruções específicas.

🌐 Erro: "DNS_PROBE_FINISHED_NXDOMAIN"

Se você vê este erro no navegador, o N8N está rodando, mas o domínio não aponta para o servidor.

Solução: Vá ao seu provedor de domínio (Cloudflare, etc.) e verifique se existe um registro Wildcard:

  • Tipo: A
  • Nome: *.easypanel (ou apenas * se for direto no domínio raiz)
  • Valor: IP da sua VPS

🆘 Erro: "Received SIGTERM / Loop de Reinício"

Se o n8n diz "Ready" mas reinicia sozinho logo depois, o Health Check está falhando.

A Solução já está incluída: O JSON gerado agora inclui uma configuração de healthCheck apontando para /healthz.

🛠️ Configuração dos IDs (Preencha Aqui)

Use os comandos abaixo para encontrar os IDs e cole nos campos. Os comandos de migração serão atualizados automaticamente.

Como obter os IDs? Copie e rode no terminal:

1. N8N Antigo: docker ps --format "table {{.ID}}\t{{.Names}}\t{{.Image}}"
2. Novo Postgres: docker ps | grep postgres
3. Novo Editor: docker ps | grep n8n_editor

🔄 Restauro Limpo de Backup SQL (.sql)

Se o seu login não funcionou, é porque o n8n criou tabelas vazias antes do import. Execute os passos abaixo na ordem exata:

1. Copiar Arquivo para Postgres

docker cp /root/backup_n8n.sql ID_POSTGRES:/tmp/backup_n8n.sql

2. Parar N8N e Limpar Banco (CRÍTICO)

Isso remove o banco vazio criado automaticamente para que o backup possa ser restaurado corretamente.

2.1 Parar o Editor do N8N:

docker stop ID_NOVO_EDITOR

2.2 Apagar tabelas existentes (Reset):

docker exec -it ID_POSTGRES psql -U postgres -d agentes-de-ia -c "DROP SCHEMA public CASCADE; CREATE SCHEMA public;"

3. Importar e Reiniciar

3.1 Importar o SQL (Agora em banco limpo):

docker exec -it ID_POSTGRES psql -U postgres -d agentes-de-ia -f /tmp/backup_n8n.sql

3.2 Iniciar o N8N:

docker start ID_NOVO_EDITOR

Agora sim! O seu login antigo deve funcionar.

Outros Métodos: Exportar/Importar JSON

1. Resgatar Chave (Se necessário):

docker exec ID_ANTIGO cat /home/node/.n8n/config

2. Exportar (Antigo):

docker exec -it ID_ANTIGO n8n export:workflow --all --output=/home/node/w.json
docker exec -it ID_ANTIGO n8n export:credentials --all --output=/home/node/c.json
docker cp ID_ANTIGO:/home/node/w.json ./w.json
docker cp ID_ANTIGO:/home/node/c.json ./c.json

3. Importar (Novo):

docker cp ./w.json ID_NOVO_EDITOR:/home/node/w.json
docker cp ./c.json ID_NOVO_EDITOR:/home/node/c.json
docker exec -it ID_NOVO_EDITOR n8n import:workflow --input=/home/node/w.json
docker exec -it ID_NOVO_EDITOR n8n import:credentials --input=/home/node/c.json
